# Fluxo de pizza

1. START: Apresenta as opções de sabor único ou dois sabores
2. FLAVOR: Permite a seleção de sabor(es) da pizza
3. QUANTITY: Solicita a quantidade de pizzas desejada
4. CRUST: Permite a escolha do tipo de borda
5. NOTE: Solicita observações adicionais para o pedido
6. FINISH: Apresenta o resumo e confirma o pedido
