# Fluxo base

Este é o fluxo base que todos os outros fluxos estendem. Ele contém:

1. Gerenciamento de estado: Acesso ao gerenciador de estado para persistir e recuperar dados
2. Construtor de resposta: Métodos para construção padronizada de respostas
3. Método handle: Método abstrato implementado por cada fluxo específico
